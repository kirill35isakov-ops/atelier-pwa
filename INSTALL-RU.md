# Ателье — установка на iPhone

Собрана первая рабочая локальная версия CRM. Это PWA, а не IPA для App Store.

## Что в архивах
- atelier-pwa.zip — готовое приложение (HTML, JavaScript, CSS, иконки, офлайн-оболочка). Сборка на сервере не требуется.
- atelier-source.zip — исходники, документация и тесты.

## Как установить
Готовые файлы нужно один раз разместить на статическом HTTPS-хостинге в корне отдельного адреса. Backend и база данных на хостинге не нужны. Автоматическая публикация в этой сессии не выполнена из-за запрета записи Git-метаданных среды.

1. Распаковать atelier-pwa.zip и разместить содержимое по HTTPS с index.html в корне.
2. Открыть адрес в Safari на iPhone.
3. Поделиться → На экран Домой → Добавить.
4. Запустить с нового значка и дождаться первой полной загрузки с интернетом.
5. Создать пароль и базу внутри установленного приложения.
6. Добавить услуги, мастеров и клиентов. Новые записи создаются кнопкой +.

ZIP нельзя просто открыть в «Файлах» и установить как приложение. Для PWA нужен HTTPS-адрес. После первой полной загрузки основной функционал работает офлайн.

## Данные и стоимость
У приложения нет подписки и платных API. Все данные на устройстве, в зашифрованной IndexedDB. Облачной синхронизации и отдельных аккаунтов сотрудников нет. Для самой оболочки можно использовать бесплатный тариф статического хостинга, соблюдая его ограничения.

После каждого рабочего дня: Ещё → Настройки → Сохранить копию в Файлы. Пароль нужен для входа и восстановления; восстановить забытый пароль невозможно. При удалении данных Safari или PWA база может удалиться. Safari и установленное приложение могут иметь раздельное хранилище; переносите данные через резервную копию.

## Возможности
Журнал, клиенты и история, сотрудники, услуги, учет оплаты (в том числе несколькими способами), скидки и бонусы, дни рождения, аналитика, аудит, CSV, резервные копии. Демонстрация с 50 вымышленными клиентами не сохраняется в рабочую базу.

Склад, зарплата, сертификаты, абонементы, внешние уведомления и серверные роли в эту первую версию не входят. Учёт оплаты не является эквайрингом или фискальной кассой.

## Проверено
Production build и TypeScript; 13 автоматических тестов (включая шифрование, неверный пароль и поврежденную копию). Интерфейс проверен в браузере при ширине 390px, в деморежиме завершён визит с разделённой оплатой. Установка и жизненный цикл Safari на физическом iPhone в этой среде не проверялись.
